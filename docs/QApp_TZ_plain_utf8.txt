1. Название проекта
Smart University Profile
Умная страница профиля университета — персонализированный помощник абитуриента внутри платформы QApp.
2. Краткое описание проекта
Smart University Profile — это улучшенная страница университета на платформе QApp. В отличие от стандартной информационной карточки, эта страница работает как персональный admissions-консультант: она анализирует профиль студента и объясняет, подходит ли ему университет, какие программы наиболее релевантны, какие документы уже готовы, что ещё нужно сделать и к какому дедлайну.
Проект реализуется как frontend-прототип, в котором персонализация строится на профиле студента. Backend, загрузка документов и база данных — опциональные улучшения, реализация которых приветствуется, но не является обязательной для MVP.
3. Проблема
Текущая страница университета на QApp имеет следующие ограничения:
•  Информация есть, но подаётся «сухо» — студент читает, но не понимает, что с этим делать
•  Нет персонализации: список программ одинаков для всех, независимо от интересов студента
•  Документы и дедлайны не превращены в понятный action plan
•  Нет ощущения «умного помощника» — страница пассивна
•  Мало интерактивности: нет фильтров, прогресс-баров, чеклистов
•  Студенту сложно быстро понять: «Мои ли это программы? Успею ли я? Что загрузить?»
•  Отсутствует визуальная иерархия приоритетов — всё одинаково важно
4. Цель продукта
Создать страницу профиля университета, которая работает как мини-admissions advisor: помогает студенту за одно посещение страницы понять, подходит ли ему этот университет, принять решение и сделать первый шаг к подаче заявки.
Страница должна отвечать на 7 ключевых вопросов студента:
•  1. Подходит ли мне этот университет?
•  2. Какие программы мне подойдут?
•  3. Какие документы нужны и что уже готово?
•  4. Что ещё нужно сделать?
•  5. Когда критичный дедлайн?
•  6. Какие следующие шаги?
•  7. Почему именно этот университет — хороший выбор для меня?
5. Целевая аудитория
Основная: школьники 10–12 классов, абитуриенты из Казахстана
Вторичная: родители, которые помогают с выбором университета
Дополнительно: студенты, выбирающие между несколькими вузами
Общий портрет: пользователи, которым нужна помощь с документами, дедлайнами и выбором программы
6. MVP Scope — что обязательно сделать
Следующие блоки являются обязательными. Остальные (backend, загрузка файлов, база данных) — опциональны и приветствуются как улучшение.
•  ✓  Responsive university profile page (desktop + mobile)
•  ✓  Hero section: название университета, город, фото/фон, badges, CTA-кнопки
•  ✓  Блок «AI Fit / Your Match» — персонализированный fit score
•  ✓  Список программ с поиском и фильтрами
•  ✓  Admission requirements checklist с прогресс-баром
•  ✓  Deadlines timeline — визуальная шкала дедлайнов
•  ✓  Scholarships section — блок стипендий с AI-инсайтом
•  ✓  Sticky sidebar summary — краткий итог справа на desktop
•  ✓  Профиль студента (mock data или реальный — на усмотрение команды)
•  ✓  Логика персонализации на основе профиля студента
•  ✓  Clean modern UI в стиле QApp
Опциональные улучшения (не обязательны, но ценятся):
•  ○  Backend для хранения профиля студента и данных университетов
•  ○  Загрузка реальных файлов документов
•  ○  База данных с несколькими университетами Казахстана
•  ○  Интеграция с реальными данными университетов
•  ○  Настоящий AI backend для рекомендаций
•  ○  Авторизация и сохранение прогресса пользователя
7. Out of Scope — что точно НЕ нужно делать
Следующие вещи не нужны ни в каком виде — не тратьте на них время:
•  ✕  Оплата / транзакции любого вида
•  ✕  Полноценная admin panel для сотрудников университетов
•  ✕  Scraping данных с внешних сайтов

10. Основные блоки интерфейса
A. Header / Navbar
•  Логотип QApp — sticky сверху
•  Навигация: Universities & Ranking · About · Apply · Blog
•  Правая часть: иконка языка, аватар профиля студента
•  Кнопка «Apply to [University Name]» — основная CTA
•  На mobile: компактная версия или hamburger menu
B. Hero Section
•  Большое фото кампуса или градиентный фон с паттерном
•  Название университета (на русском и английском)
•  Город и страна
•  Badges: язык обучения · стипендии · дедлайн · AI Match
•  Маленький AI-инсайт: «AI Fit: Strong match based on your profile»
•  CTA кнопки: Start Application · Save · Compare
C. AI Fit Section — ключевой блок
•  Overall Fit Score: XX% — визуализировать как ring/circle chart
•  Status badge: Qualified / Strong Match / Partial Match / Low Match
•  Секция «Почему подходит»: список зелёных причин на основе профиля студента
•  Секция «Gaps / Риски»: список предупреждений (missing docs, score gaps и т.д.)
•  Рекомендованные следующие шаги: пронумерованный action list
•  Логика: fit score и reasons вычисляются из профиля студента и данных вуза
D. Programs Section
•  Search input: «Search programs...»
•  Фильтры: Field · Language · Degree · Fit Score
•  Program cards: название, duration, language, fit score, match reason
•  Кнопки на карточке: «View requirements» · «Add to shortlist»
•  Shortlist сохраняется в state (с backend — в профиле пользователя)
•  Программы сортируются по fit score по умолчанию
E. Deadlines Timeline
•  Визуальная вертикальная timeline (не просто список)
•  Шаги: Today → Complete Profile → Upload Docs → Choose Programs → Submit → Review
•  Цветовая индикация статусов: current / action needed / deadline / future
•  AI-warning: уведомление о недостающих документах
•  Конкретные даты из данных университета
F. Admission Requirements Checklist
•  Документы сгруппированы по статусу: Ready · Missing · Pending
•  Прогресс-бар: «X of N required documents ready»
•  Каждая строка: иконка + название документа + статус-badge + кнопка действия
•  Кнопки: Upload (для missing) · Complete (для pending) · ✓ (для ready)
•  Если реализован backend — Upload может загружать настоящий файл
G. Scholarships Section
•  Карточки доступных стипендий
•  Каждая карточка: название · кто может подать · что подготовить · кнопка действия
•  Relevance badge: High / Medium / Low (на основе профиля студента)
•  AI note: объяснение почему стипендия важна для данного студента
H. Sidebar Summary — sticky на desktop
•  Fit score card: XX% · статус · количество pending actions
•  Application checklist: краткий список шагов с чекбоксами
•  Quick info: City · Programs · Language · Deadline
•  Contact links: официальный сайт · email приёмной комиссии
•  CTA: Start Application · Ask AI Advisor
•  На mobile: становится обычной карточкой (не sticky)
I. AI Advisor Mock / Chat
•  Блок «Ask AI about this university»
•  Suggestion pills: «Which program fits me?» · «What docs am I missing?» и др.
•  Input field для ввода вопроса + кнопка Ask
•  Если реализован AI backend — настоящие ответы на основе данных вуза и профиля
•  Если без backend — фиксированные mock-ответы на каждый suggestion
J. Comparison Block
•  «Compare with other universities» — карточки других казахстанских вузов
•  Fit score каждого вуза, название, город
•  CTA «Add to comparison» или полноценный comparison view
•  Если реализована база данных — показывать реальные вузы из неё
K. Footer
•  Логотип QApp
•  Ссылки на разделы платформы
•  Ссылки на аккаунт: My Applications · Saved · Settings
•  Legal: Privacy Policy · Terms of Use
•  Город и контакты платформы
11. UX Requirements
•  Информация должна легко сканироваться — самое важное наверху
•  Чёткая иерархия: Fit score → Deadline → Documents → Programs → Details
•  Минимум текста, максимум визуальных статусов (badges, icons, progress bars)
•  Progressive disclosure: «Show more» для длинных секций, expandable cards
•  Hover states на всех интерактивных элементах
•  Smooth transitions и subtle animations
•  На мобильной версии: sidebar не sticky, программы — карточки в одну колонку
•  Критичные элементы (deadline, missing docs) — визуально выделены
•  Next steps должны быть понятны без дополнительных объяснений
•  Страница должна работать как шаблон для любого казахстанского университета

13. Требования к README.md
README должен содержать следующие разделы:
1.  Project overview — что это и зачем
2.  Problem statement — какую проблему решает
3.  Solution — как именно решает
4.  Features — список реализованных функций
5.  Tech stack — чем сделано
6.  How to run — инструкция запуска проекта
7.  Data explanation — откуда данные: mock, база или реальные
8.  Screenshots — хотя бы 2–3 скриншота страницы
9.  Limitations — что не реализовано и почему
10.  Future improvements — что можно добавить в продакшне
14. Критерии оценки
Соответствие задаче: решает ли проект поставленную задачу платформы QApp
Полезность для абитуриента: помогает ли страница студенту принять решение
Качество UI/UX: выглядит ли современно, чисто, удобно
Персонализация: работает ли логика fit score и recommendations
Реалистичность MVP: работает ли прототип стабильно без критичных багов
Глубина реализации: наличие backend, реальных данных, загрузки файлов — плюс
Презентация: понятно ли объяснено решение, есть ли слайды/видео
Объяснение решения: может ли команда ответить на вопросы жюри

16. Возможные улучшения после MVP
Что можно добавить в полноценной версии продукта:
•  Real university database — тысячи вузов из Казахстана и за рубежом
•  AI recommendations backend (Claude API / OpenAI) для умных советов
•  Application tracking — отслеживание статуса поданных заявок
•  University comparison engine — детальное сравнение 2–4 вузов
•  Chatbot advisor — настоящий диалог с AI на основе данных вуза
•  Multilingual support — интерфейс на казахском, русском и английском
•  Analytics для приёмных комиссий — статистика поведения абитуриентов
•  Mobile app — React Native или PWA версия
•  Notifications — напоминания о дедлайнах по email или SMS
17. Итоговая формулировка MVP
За 48 часов команда должна создать интерактивный прототип Smart University Profile, где студент видит персональный fit score, подходящие программы, дедлайны, checklist документов и чёткие next steps. Страница должна быть шаблонной — применимой к любому университету Казахстана. Минимум — работающий frontend с умной логикой персонализации. Максимум — полноценный продукт с backend, реальными данными и загрузкой документов. Не просто карточка университета — а мини-admissions advisor в браузере.
