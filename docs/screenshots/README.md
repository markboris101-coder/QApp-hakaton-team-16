# Скриншоты для README

Ожидаемые имена (см. корневой README §8):

1. **`landing.png`** — лендинг с анкетой  
2. **`dashboard.png`** — дашборд вуза (AI Fit, программы)  
3. **`profile.png`** *(опционально)* — профиль или каталог  
4. **`blog.png`** *(опционально)* — страница `/blog` (поиск, теги)

Формат: PNG или JPG. Снимите после `npm run dev`, положите файлы сюда, затем `git add docs/screenshots/*.png` и коммит.
