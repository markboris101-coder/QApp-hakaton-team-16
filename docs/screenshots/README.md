# Скриншоты для README

Положите сюда **2–3** изображения интерфейса (PNG или JPG), например:

1. `landing.png` — лендинг с анкетой  
2. `dashboard.png` — дашборд вуза (AI Fit, программы)  
3. `profile.png` или `catalog.png` — профиль или каталог / сравнение  

В корневом **README.md** раздел *Screenshots* ссылается на эти файлы — после добавления раскомментируйте строки с `![…](docs/screenshots/…)` или обновите пути.
