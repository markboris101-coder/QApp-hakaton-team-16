# Каталог вузов QApp

## Как добавить вуз

1. Скопируйте `_example.university.json` в новый файл `ваш-id.json` (латиница, дефисы можно — например `my-institute.json`).
2. Заполните поля по образцу существующих файлов в `universities/` (удобнее править большие блоки в редакторе с JSON-схемой или подсказками из соседнего вуза).
3. В терминале из корня репозитория выполните:

```bash
npm run catalog:bundle
```

Это пересоберёт **`universities.bundle.json`** из всех `universities/*.json` (файлы с именем на `_` в начале в бандл не попадают).

4. Перезапустите фронт / сервер при необходимости — Vite подхватит обновлённый JSON.

## Файлы

| Путь | Назначение |
|------|------------|
| `universities/<id>.json` | По одному вузу — источник правды для названий, программ, дедлайнов и т.д. |
| `universities.bundle.json` | Сгенерированный массив всех вузов (не редактировать руками). |
| `../data/universityDatabase/extraFaculties.ts` | Дополнительные факультеты, подмешиваются к данным из JSON по `id` вуза. |

## Служебные скрипты

- `npm run catalog:bundle` — сборка бандла из папки `universities/`.
- `node scripts/seed-ten-kz-universities.mjs` — **демо**: добавляет пакет из 10 казахстанских вузов (если файлов с такими `id` ещё нет); после выполнения всегда запускайте `npm run catalog:bundle`.
- `npx tsx scripts/dump-catalog-from-mockdata.ts` — **редко**: если нужно заново выгрузить каталог из кода в отдельные JSON (до изменений в `mockData`).

Типы полей описаны в `UniversityTemplate` в `src/mockData.ts`.
